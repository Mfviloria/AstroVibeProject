# 🌌 Exoplanet Explorer NASA

An interactive Streamlit dashboard for exploring confirmed exoplanets using data from the NASA Exoplanet Archive. The application allows users to analyze planetary characteristics, discovery trends, stellar systems, and potential habitability through dynamic visualizations and filtering tools.

## 🚀 Live Demo

**[exoplanetexplorernasa.streamlit.app](https://exoplanetexplorernasa.streamlit.app)**

## ✨ Features

- 🪐 Explore confirmed exoplanets from NASA datasets
- 🔎 Filter planets by physical and orbital characteristics
- 📈 Interactive charts and visual analytics
- 🌍 Identify potentially habitable or Earth-like candidates
- ⭐ Analyze host star properties and planetary systems
- 📊 Compare planets using customizable parameters
- 📥 Export filtered datasets for further analysis

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Pandas**
- **NumPy**
- **Plotly / Altair** — interactive visualizations
- **NASA Exoplanet Archive** — official public data source

## ▶️ Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/your-username/exoplanet-explorer-nasa.git
cd exoplanet-explorer-nasa
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Run the Streamlit application**

```bash
streamlit run app.py
```

**4. Open your browser at**

```text
http://localhost:8501
```

## 📊 Data Source

This project uses publicly available data from the **NASA Exoplanet Archive**, maintained by Caltech/IPAC under contract with NASA.

🔗 [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/)

## 🌍 Why This Project?

The goal of this project is to make exoplanet exploration more accessible through interactive data visualization. By transforming raw astronomical data into an intuitive dashboard, users can better understand how exoplanets are discovered, compare planetary systems, and investigate potentially habitable worlds beyond our solar system.
